TEACHER'S DAY SURPRISE
=======================

This is a complete HTML/CSS/JavaScript Teacher's Day experience.

FILES
-----
index.html  - Main page
style.css   - Design and animations
script.js   - Interactions

HOW TO EDIT
-----------
1. Open the folder in VS Code.
2. Open index.html with Live Server.
3. In index.html, replace:
   - "Your Teacher" with your teacher's name.
   - "Your Student" with your name.
4. You can also change any message directly in the HTML.

NO INSTALLATION REQUIRED
------------------------
It works as a normal website in a browser.

TIP FOR TOMORROW
----------------
Before sending it, test it on your phone. You can upload the folder to
GitHub Pages, Netlify, Vercel, or another static hosting service and send
your teacher the website link.
